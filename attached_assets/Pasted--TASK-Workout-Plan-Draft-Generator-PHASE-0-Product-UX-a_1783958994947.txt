# TASK — Workout Plan Draft Generator
# PHASE 0: Product, UX and Technical Specification

Design a complete, trainer-controlled process for generating a workout-plan draft based on the existing application data.

This task is an AUDIT AND SPECIFICATION task only.

Do NOT implement the generator.
Do NOT modify the database.
Do NOT create migrations.
Do NOT modify Workout Builder production behaviour.
Do NOT generate or save plans.
Do NOT modify volume formulas or guideline values.
Do NOT implement AI.

Create the specification document:

docs/workout-plan-draft-generator-spec.md

============================================================
CORE PRODUCT PRINCIPLE
============================================================

The application should generate:

Szkic planu treningowego

It must not create an unquestionable final plan.

The trainer must always retain control over:

- training split,
- weekly volume,
- exercises,
- sets,
- repetitions,
- RIR,
- tempo,
- rest periods,
- warm-up,
- plan saving,
- plan activation.

Recommended trainer actions:

- Wygeneruj propozycję planu
- Edytuj założenia
- Przelicz objętość
- Zamień ćwiczenie
- Zapisz jako szkic
- Zatwierdź plan

The system should calculate and recommend, but never replace the trainer.

============================================================
STEP 2 — DESIGN A SIMPLE TRAINER FLOW
============================================================

Design a convenient wizard with a maximum of 5 steps.

The process must be easy for a beginner trainer while allowing advanced trainers to edit every recommendation.

Recommended entry points:

- Client profile → Utwórz plan
- Workout Builder → Wygeneruj szkic

Recommended wizard:

STEP 1 — Klient i dane wejściowe

Show a concise summary:

- main goal,
- experience level,
- available training days,
- session duration,
- training location,
- available equipment,
- daily activity,
- physical work,
- sleep,
- stress,
- health limitations,
- priority muscle groups,
- excluded muscle groups,
- preferred exercises,
- avoided exercises.

Show missing critical information clearly.

Do not force the trainer to reopen the whole Training Interview.

STEP 2 — Założenia planu

Allow confirmation or override of:

- number of training days,
- session duration,
- training split,
- block duration,
- main goal,
- priority muscle groups,
- training style,
- optional trainer restrictions.

Prefill values from the Training Interview.

Hide advanced settings initially using progressive disclosure.

STEP 3 — Objętość tygodniowa

For every existing volume target show:

- recommended range for the selected experience level,
- suggested starting value,
- reason for the suggestion,
- recovery adjustment,
- priority adjustment,
- trainer override.

Example:

Klatka piersiowa

Zakres dla poziomu:
8–12 serii efektywnych

Proponowany start:
9 serii efektywnych

Powody:
- standardowy priorytet,
- średnia regeneracja,
- 3 dni treningowe.

STEP 4 — Wygenerowany szkic

Show:

- training days,
- exercise order,
- exercises,
- working sets,
- repetition ranges,
- RIR,
- tempo,
- rest periods,
- general warm-up,
- preparation sets,
- weekly effective volume,
- estimated session duration,
- warnings,
- explanations for important decisions.

STEP 5 — Review and save

Allow:

- editing every prescription,
- replacing exercises,
- moving exercises,
- changing sets,
- recalculating volume,
- accepting non-blocking warnings,
- saving as draft.

Do not activate the plan automatically.

STEP 3 — DEFINE GENERATOR INPUTS
============================================================

Create a decision matrix for every generator input.

For every field specify:

- data source,
- required or optional,
- missing-data behaviour,
- effect on generation,
- default value,
- whether trainer override is allowed.

Include at minimum:

- clientId
- experienceLevel
- trainingGoal
- availableDays
- sessionDuration
- trainingLocation
- availableEquipment
- dailyActivity
- physicalWork
- sleep
- stress
- recoveryQuality
- healthLimitations
- priorityMuscleGroups
- excludedMuscleGroups
- preferredExercises
- avoidedExerciseIds
- avoidedExerciseReasons
- planBlockDuration
- preferredTrainingStyle

Experience level is required.

For missing or invalid experience level:

- block draft generation,
- return MISSING_EXPERIENCE_LEVEL or INVALID_EXPERIENCE_LEVEL,
- do not map to Brak aktywności fizycznej,
- do not map to Początkujący.

============================================================
STEP 4 — DEFINE FOUR EXPERIENCE PROFILES
============================================================

Use exactly:

1. Brak aktywności fizycznej
2. Początkujący
3. Średniozaawansowany
4. Zaawansowany

For every level define recommended defaults for:

- position inside the weekly volume range,
- exercises per session,
- working sets per exercise,
- technical complexity,
- stable vs free-weight exercise preference,
- compound vs isolation balance,
- bilateral vs unilateral balance,
- repetition ranges,
- RIR,
- proximity to failure,
- tempo complexity,
- rest periods,
- warm-up complexity,
- frequency,
- maximum number of demanding exercises,
- progression model.

These are recommendations, not hard restrictions.

Suggested direction:

Brak aktywności fizycznej:
- lower part of the approved volume range,
- simple and stable exercises,
- RIR 3–4,
- no planned muscular failure,
- controlled tempo,
- low technical complexity,
- low neurological fatigue,
- conservative DOMS potential.

Początkujący:
- lower-to-middle volume range,
- RIR 2–3,
- repeatable movement patterns,
- simple progression.

Średniozaawansowany:
- middle range,
- RIR 1–3,
- more exercise variety,
- priorities may receive additional volume.

Zaawansowany:
- individually selected range,
- RIR 0–2 depending on exercise safety,
- advanced options only with trainer approval.

============================================================
STEP 5 — WEEKLY VOLUME MODEL
============================================================

Design how the system chooses the starting weekly volume inside the existing approved range.

Use the existing guideline rows.

Do not change:

- volume formulas,
- 44 volume-guideline rows,
- 11 volume targets,
- max-coefficient-per-target logic.

The starting value should consider:

- experience level,
- muscle priority,
- available days,
- session duration,
- sleep,
- stress,
- physical work,
- daily activity,
- recovery quality,
- previous training exposure.

General direction:

Lower range:
- inactivity,
- return after a break,
- poor recovery,
- short sessions,
- high stress,
- demanding physical work.

Middle range:
- stable schedule,
- standard priority,
- average recovery.

Upper range:
- experienced client,
- priority muscle,
- good recovery,
- enough training time,
- trainer approval.

Every selected value must include a trainer-readable explanation.

============================================================
STEP 6 — VOLUME DISTRIBUTION
============================================================

Design how weekly effective volume is distributed between training days.

Define rules for:

- one exposure per week,
- two exposures,
- three exposures,
- priority-muscle frequency,
- recovery spacing,
- minimum useful volume per session,
- maximum reasonable volume per session.

Do not place all weekly volume for a muscle in one session when a better distribution is possible.

The system must compare:

- target weekly volume,
- generated effective volume,
- difference,
- tolerance status.

Warm-up sets must never count as working volume.

============================================================
STEP 7 — TRAINING SPLIT
============================================================

Design explainable split recommendations.

Possible starting options:

2 days:
- Full Body A/B

3 days:
- Full Body
- Upper / Lower / Full Body

4 days:
- Upper / Lower
- priority-based four-day split

5 days:
- specialist split
- Upper / Lower variants
- Push / Pull / Legs variants

6 days:
- advanced structures only when appropriate

The trainer may always choose another split.

Define which client inputs influence the recommendation.

============================================================
STEP 8 — EXERCISE SELECTION
============================================================

Design deterministic exercise selection using the existing Exercise Library.

Do not use AI.

Create separate lists of:

Hard filters:
- inactive exercise,
- unavailable required equipment,
- incompatible training location,
- missing critical metadata.

Soft ranking factors:
- suitable experience level,
- training goal,
- movement pattern,
- movement category,
- muscle contribution,
- client priority,
- preferred exercise,
- learning difficulty,
- joint stress,
- neurological fatigue,
- DOMS potential,
- exercise priority,
- requires spotter,
- can be performed to failure,
- progression or regression availability.

Avoided exercises:

- must show CLIENT_AVOIDS_EXERCISE,
- must receive a ranking penalty,
- must not be automatically blocked,
- trainer can still choose them.

Health limitations must generate warnings and trainer review.

Do not create medical diagnoses or automatic medical decisions.

============================================================
STEP 9 — EXERCISE ORDER
============================================================

Design ordering rules.

Recommended starting structure:

1. general warm-up,
2. movement preparation,
3. priority exercise,
4. technically demanding compound exercises,
5. other compound exercises,
6. accessory exercises,
7. isolation exercises,
8. core,
9. carry or optional finisher.

Define exceptions for:

- priority muscle groups,
- motor preparation,
- fatigue interference,
- beginner-friendly exercise order,
- equipment efficiency.

============================================================
STEP 10 — SET ALLOCATION
============================================================

Design an iterative process:

1. Select candidate exercises.
2. Assign initial working sets.
3. Calculate effective volume with existing muscle coefficients.
4. Compare result with weekly targets.
5. Add, remove or redistribute sets.
6. Recalculate.
7. Stop within accepted tolerance.
8. Report unresolved gaps.

Define suitable tolerances without changing the existing calculator.

Example:

Target:
10 effective sets

Generated:
9.5

Status:
within tolerance

The trainer must see the target and generated values.

============================================================
STEP 11 — REPETITIONS, RIR, TEMPO AND REST
============================================================

Design prescription rules based on:

- goal,
- exercise type,
- equipment,
- experience level,
- technical difficulty,
- joint stress,
- safety,
- muscle group.

Do not assign 3 × 10 to every exercise.

Suggested repetition ranges:

- main strength compound: 4–8
- hypertrophy compound: 6–12
- machines: 8–15
- isolation: 10–20
- calves and lateral raises: 12–25
- core: repetitions or time
- carries: distance or time

Suggested RIR profiles:

- Brak aktywności fizycznej: 3–4
- Początkujący: 2–3
- Średniozaawansowany: 1–3
- Zaawansowany: 0–2 depending on exercise safety

Tempo must remain simple and understandable.

Examples:

- 3-1-1-0
- Kontrolowane opuszczanie, dynamiczne podniesienie

Suggested rest ranges:

- heavy compound: 2–4 minutes
- standard compound: 90–180 seconds
- accessory: 60–150 seconds
- isolation: 60–120 seconds
- preparation drill: 30–90 seconds

Do not reduce rest below a reasonable level only to fit session duration.

============================================================
STEP 12 — WARM-UP
============================================================

Design two layers:

A. General and movement preparation

- temperature increase,
- movement preparation,
- technical rehearsal,
- joint-specific preparation where justified.

B. Exercise preparation sets

Use preparation sets only for exercises that need them.

Possible structure:

- very light load,
- approximately 40% of working load,
- approximately 60%,
- approximately 80%,
- working sets.

Audit whether the current plan model supports set types.

For MVP recommend at minimum:

- Rozgrzewkowa
- Robocza

Warm-up sets must not count toward weekly effective volume.

============================================================
STEP 13 — SESSION DURATION
============================================================

Design a session-duration estimate using:

- general warm-up,
- preparation sets,
- working sets,
- repetition duration,
- tempo,
- rest periods,
- exercise transitions,
- equipment changes.

Display:

Szacowany czas:
58 minut

Dostępny czas:
60 minut

Status:
Mieści się w limicie

When time is exceeded, suggest changes but do not silently apply them.

Possible suggestions:

- remove a low-priority exercise,
- reduce non-priority sets,
- use a more efficient substitution,
- adjust exercise order,
- adjust rest only where reasonable.

============================================================
STEP 14 — PROGRESSION MVP
============================================================

Define a simple double-progression model.

Example:

Range:
8–12 repetitions

Target:
RIR 2

Rule:
When all working sets reach 12 repetitions at the target RIR, increase load next session and return to the lower part of the repetition range.

Also define simple progression for:

- bodyweight exercises,
- time-based exercises,
- carries.

Do not design advanced periodization for MVP.

The generator process must be:

- quick,
- readable,
- beginner-friendly,
- editable by advanced trainers,
- transparent,
- keyboard accessible,
- responsive,
- consistent with the current trainer app.

- one enormous form,
- unnecessary required fields,
- hidden decisions,
- automatic plan activation,
- complicated technical language without helper text.

Prefer:

- automatic prefilling,
- concise summaries,
- progressive disclosure,
- editable recommendations,
- explanations on demand,
- visible target-vs-generated volume.
