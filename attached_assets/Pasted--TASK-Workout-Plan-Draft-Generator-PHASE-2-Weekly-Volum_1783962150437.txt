============================================================

- adjustments that influenced the recommendation,

============================================================
STEP 4 — BASE RANGE POSITION
============================================================

Select a starting point inside the approved range.

Use deterministic rules.

Approved base positions:

Brak aktywności fizycznej:
- lower boundary of the approved range
- rangePosition = 0.00

Początkujący:
- approximately 25% inside the range
- rangePosition = 0.25

Średniozaawansowany:
- middle of the range
- rangePosition = 0.50

Zaawansowany:
- middle of the range by default
- rangePosition = 0.50

Formula:

baseValue =
guidelineMin
+
(guidelineMax - guidelineMin) * rangePosition

Round according to the existing effective-volume precision.

Prefer 0.5-set precision if supported by the existing calculator.

Do not round all values to whole numbers when coefficients already produce half sets.

============================================================
STEP 5 — PRIORITY ADJUSTMENT
============================================================

Priority muscle groups may move the recommended value upward inside the approved range.

Design deterministic adjustment rules.

Recommended starting rule:

- first priority: +20% of the available range width
- second priority: +10%
- third priority: +5%

Example:

Range:
8–12

Base:
10

First priority adjustment:
+0.8

Recommended:
10.8
Rounded:
11.0

Never exceed guidelineMax.

Excluded muscle groups:

- should not automatically become zero,
- should move toward the lower boundary,
- should generate a trainer-facing explanation,
- trainer can manually adjust.

Suggested excluded-group adjustment:

- set recommendation to guidelineMin,
- add notice:
  TARGET_DEPRIORITIZED_BY_TRAINER

Do not remove an anatomical target from the system.

============================================================
STEP 6 — RECOVERY ADJUSTMENT
============================================================

Use available recovery-related data conservatively.

Factors:

- sleep,
- stress,
- physical work,
- daily activity,
- recovery quality.

Create one deterministic recovery score.

Example direction:

Good recovery:
- good sleep,
- low or moderate stress,
- no demanding physical work.

Neutral recovery:
- incomplete or average data.

Reduced recovery:
- poor sleep,
- high stress,
- demanding physical work,
- very high daily activity.

Recommended adjustment:

Good recovery:
- no automatic increase in MVP,
- keep base or priority-adjusted value,
- show positive explanation.

Neutral:
- no adjustment.

Reduced recovery:
- move recommendation downward by 10–25% of the range width.

For Brak aktywności fizycznej:

- do not go below guidelineMin,
- remain at the lower boundary.

Do not treat missing recovery data as poor recovery.

Missing data should create:

MISSING_RECOVERY_DATA

This warning is non-blocking.

============================================================
STEP 7 — AVAILABILITY ADJUSTMENT
============================================================

Consider:

- trainingDays,
- sessionDuration.

The weekly guideline range itself must remain unchanged.

Availability affects the recommended starting value, not the approved range.

Suggested rules:

Short availability:

- 1–2 days,
- or session duration below 45 minutes.

Result:

- move non-priority targets toward the lower part of the range,
- preserve priority targets where possible,
- show:
  LIMITED_TRAINING_AVAILABILITY

Standard availability:

- 3–4 days,
- 45–90 minutes.

Result:

- no adjustment.

High availability:

- 5–6 days,
- sufficient session duration.

Result:

- do not automatically increase volume in Phase 2,
- only note that distribution flexibility is better.

Do not create volume that cannot later fit into the session structure.

============================================================
STEP 8 — ORDER OF CALCULATION
============================================================

Use a documented order:

1. Load approved guideline range.
2. Select experience-based base position.
3. Apply priority adjustment.
4. Apply excluded-group adjustment.
5. Apply recovery adjustment.
6. Apply availability adjustment.
7. Clamp inside approved range.
8. Round to supported precision.
9. Apply trainer override if present.
10. Generate explanations and warnings.

The same input must always produce the same result.

No randomness.
