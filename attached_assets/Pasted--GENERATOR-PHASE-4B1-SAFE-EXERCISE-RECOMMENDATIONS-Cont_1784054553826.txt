2. REUSE THE EXISTING ENGINE
============================================================

recommendation scoring and reasons.

Do not duplicate scoring in React.

Do not change the numeric recommendation score.

Use an existing recommendation endpoint when possible.

A minimal read-only generator adapter or endpoint is allowed only when it

============================================================
3. RECOMMENDATIONS FOR ONE DAY
============================================================

Add a button inside every workout-day section:

"Pokaż rekomendacje"

Do not load recommendations automatically when Step 4 opens.

After clicking, request recommendations using:

- target muscles assigned to the selected day,
- current client experience level,
- selected training location,
- available equipment,
- existing client limitations and preferences supported by the current engine.

Display up to 3 recommendations per target.

Deduplicate the final result by exerciseId.

An exercise matching several targets must appear once and display all matching
target labels.

Limit the final visible recommendation list to a maximum of 8 unique exercises
per workout day.

============================================================
4. AUTOMATIC COMPATIBILITY FILTERS
============================================================

Automatically exclude exercises that are:

- inactive,
- incomplete,
- incompatible with the selected training location,
- incompatible with available equipment,
- already added to the same workout day.

Do not require the trainer to manually configure these filters.

The same exercise may still be used on another workout day.

Do not silently assume full gym access.

If training location or equipment information is unavailable, show:

"Brak informacji o miejscu treningu lub dostępnym sprzęcie. Uzupełnij wcześniejsze dane, aby otrzymać dokładne rekomendacje."

Manual exercise selection must remain available.

============================================================
5. RECOMMENDATION CARD
============================================================

- exercise name,
- matching target muscles,
- equipment,
- existing recommendation score or suitability label,
- existing recommendation reason,
- warnings supported by current metadata,
- button:

"Dodaj do dnia"

Do not create new recommendation explanations when an existing reason is
available.

============================================================
6. AVOIDED EXERCISES
============================================================

Do not change the existing numeric recommendation score.

When an avoided exercise is returned by the existing engine:

- display:

"Klient wskazał, że chce unikać tego ćwiczenia."

- require the existing confirmation action:

"Zastosuj mimo ostrzeżenia"

- use avoided status only as a deterministic tie-breaker so an equally scored
  non-avoided exercise appears first.

Do not introduce a new scoring penalty formula.

If existing pain or contraindication metadata is already available, show its
existing non-blocking warning.

Do not diagnose or prescribe rehabilitation.

============================================================
7. ADDING A RECOMMENDATION
============================================================

- working sets: 3
- repetitions: 8–12
- RIR: 2
- rest: 90 seconds

- weekly volume targets,
- analytical distribution,
- other exercises,
- exercise order,
- client data.

The trainer must still be able to:

- ignore recommendations,
- use the manual exercise selector,
- edit an added exercise,
- remove an added exercise.
