==================================================
RULES
==================================================

1. Brak aktywności fizycznej

For experience level:

“Brak aktywności fizycznej”

the training-block duration must always equal:

4 weeks

Behaviour:

- automatically set the existing block-duration field to 4,
- make the control fixed or read-only,
- do not allow the user to select another duration,
- when the experience level changes to Brak aktywności fizycznej, reset the
  existing value to 4,
- display:

“Blok adaptacyjny: 4 tygodnie”

Do not change the existing adaptation-training generator behaviour.

2. Początkujący

Keep the existing available range:

4–12 weeks

3. Średniozaawansowany

Keep the existing available range:

4–12 weeks

4. Zaawansowany

Keep the existing available range:

4–12 weeks

For these three levels:

- retain the existing selectable options,
- retain the existing default value,
- preserve the currently selected value when it is between 4 and 12,
- do not automatically change a valid existing selection.

VALIDATION
==================================================

- Zaawansowany accepts whole numbers from 4 through 12.
