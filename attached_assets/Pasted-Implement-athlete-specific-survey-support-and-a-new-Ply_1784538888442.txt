==================================================

- "Nie"
- "Tak — amatorsko"
- "Tak — półzawodowo"

Optional but strongly recommended field:
"Co chcesz poprawić najbardziej?"
Suggested selectable options:
- skoczność
- szybkość
- koordynacja
- zmiana kierunku
- wydolność
- prewencja urazów
- dynamika

==================================================
FEATURE 3 — NEW SESSION TYPE: PLYO
==================================================

Add a new session type / template family:
- plyo
- "Plyometria"

Purpose:
- athletic support
- reactive ability
- landing quality
- stiffness / elasticity support
- coordination
- explosiveness

Important:
Plyo is NOT a replacement for strength training.
It is an additional session type that may coexist with:
- full_body
- upper_lower
- upper_lower_full_body
- push_pull_legs

Do NOT treat Plyo as a normal bodybuilding split.
It is an athletic-support session.

FEATURE 4 — WHEN PLYO SHOULD BE USED
==================================================

Plyo should be considered only when athlete logic is active.

Examples of valid weekly structures:
- FBW + Plyo
- FBW + Plyo x2
- Upper / Lower + Plyo
- Góra / Dół / Full Body + Plyo support day

Examples of intended meaning:
- FBW + Plyo x2 =
  1 day general strength development
  2 days athletic / plyometric support

Do NOT force Plyo for every athlete.
Use it when the sport / need profile supports it.

==================================================
FEATURE 5 — PLYO SESSION CONTENT LOGIC
==================================================

Create a clean Plyo session structure.

The session should not be random.
It should follow a sensible order.

Recommended structure example:
1. low-volume explosive jump / hop pattern
2. landing / deceleration / control pattern
3. lateral / directional movement or coordination element
4. optional supportive athletic drill
5. optional mobility / trunk / low-fatigue finish if appropriate

The exact exercise inventory depends on what already exists in the database,
but the template should be logically separated from:
- Push
- Pull
- Legs
- Upper
- Lower
- Full Body

Plyo should not become:
- random conditioning
- generic cardio
- a duplicate of Legs day
