### 1. Fix priority-selection UX

Current issue:

Required behavior:

- do not silently delete selected priorities,
- if more than one priority is selected, display:

  “Na tym poziomie możesz zachować tylko jeden priorytet. Wybierz, który pozostawić.”

- keep all currently selected priorities visible,
- allow the user to remove priorities manually,
- block interview submission while more than one remains,
- preserve the existing backend validation limiting these levels to one priority.

Do not change the behavior for intermediate and advanced clients.
