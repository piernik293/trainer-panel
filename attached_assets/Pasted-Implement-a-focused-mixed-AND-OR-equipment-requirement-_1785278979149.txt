==================================================
1. REQUIRED PRODUCT BEHAVIOUR
==================================================

Training location and available equipment are separate concepts.

“Dom” must not mean “Brak sprzętu”.

Examples:

Home + bodyweight only:
- allow true bodyweight exercises,
- exclude dumbbells, barbells, machines, cables and benches.

Home + dumbbells:
- allow true bodyweight exercises,
- allow exercises requiring only dumbbells,
- exclude exercises requiring dumbbells AND a bench,
- exclude machines, cables bodyweight exercises,
- allow exercises requiring only dumbbells,
- exclude exercises requiring dumb, barbells and kettlebells.

Home + dumbbells + bench:
- allow dumbbell-only exercises,
- allow dumbbell-and-bench exercises,
- preserve bodyweight exercises.

Home + kettlebell:
- allow kettlebell exercises and bodyweight exercises.

The place “Dom” must not block exercises when the client owns the required
equipment.

The place “Siłownia” must not automatically bypass the selected-equipment
filter unless an existing explicit product rule already means that all gym
equipment is available.

==================================================
2. MINIMUM SCHEMA CHANGE
==================================================

Keep the existing exercise column:

equipment TEXT[]

Interpret it as:

equipmentAnyOf

At least one listed item must be available.

Add:

required_equipment_all TEXT[] NOT NULL DEFAULT '{}'

Interpret it as:

equipmentAllOf

Every listed item must be available.

Compatibility formula:

all required_equipment_all items are available

AND

(
  equipment is empty
  OR at least one equipment item is available
  OR a true bodyweight option exists
)

A bodyweight option may satisfy the equipmentAnyOf part, but it must never
bypass required_equipment_all.

Example:

equipment = {Masa własnego ciała}
required_equipment_all = {Ławka}

A bodyweight-only client must be rejected because the bench is still required.

Meaning:

Maszyna AND Ławka
