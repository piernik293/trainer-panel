====================================================
PART 4 — GOAL-TO-LIBRARY RULES
====================================================

Implement explicit library-selection bias for each goal.

1. Budowa sylwetki
- prefer hypertrophy-friendly compounds
- prefer good local stimulus
- allow/support more isolation than beginner/general-health flows
- avoid random athletic/plyometric filler

2. Zwiększenie siły
- prefer main compounds and force-production patterns
- isolation may exist as support, not as the main structure

3. Redukcja tkanki tłuszczowej
- choose fatigue-efficient resistance exercises
- do NOT model fat loss as “just more exhausting exercise choices”
- keep sensible resistance training quality

4. Poprawa kondycji
- prefer simple, global, repeatable movements
- lower isolation clutter
- do NOT treat as sport-power by default

5. Poprawa sprawności
- prefer movement quality, unilateral control, body control, trunk work
- may allow some dynamic patterns when level allows
- should feel more athletic than conditioning, but less specialized than sport

6. Cel sportowy
- must use sport sub-priority inputs:
  - Dynamika
  - Szybkość
  - Stabilizacja
  - athleteStatus
- should create the strongest athletic/performance bias

====================================================
PART 5 — EXPERIENCE-SPECIFIC RULES
====================================================

A. Brak aktywności fizycznej
- prefer very simple, stable, low-complexity exercises
- heavily favor suitable_for_no_activity = true when available
- minimal isolation clutter
- no advanced plyometrics
- no unnecessary technical lifts

B. Początkujący
- allow more basic compounds than no-activity
- still prioritize simple and stable choices
- more freedom than no-activity, but not full intermediate complexity

C. Średniozaawansowany
- strongly deprioritize regression/beginner-style defaults when gym equipment exists
- plans must not be made mostly from regression exercises
- direct shoulder/arm work should not disappear entirely when structure allows

D. Zaawansowany
- allow more targeted/direct work
- allow more specialized choices
- preserve logic and hierarchy
