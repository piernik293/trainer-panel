==================================================
PROBLEM
==================================================

The current system behaves like an autofill continuation engine:
- session generation effectively starts only after one exercise already exists
- then autofill adds more exercises

This is not acceptable.

We need a true generator that can create a full day from an empty session.

==================================================
GOAL
==================================================

Build a new generation path where the system can generate a complete session from scratch using:

- dayType
- session template / slot structure
- exercise pool
- equipment/location filters
- deterministic selector V0

No preselected first exercise.
No alreadyAdded seed requirement.
The generator must start from EMPTY.

==================================================
NEW REQUIRED FLOW
==================================================

For a selected day type (push / pull / legs / upper / lower):

1. Start with an empty session
2. Load the session template for that day type
3. Iterate slot by slot
4. For each slot:
   - build candidate pool
   - apply hard filters
   - select one valid exercise
   - add it to session
   - add it to usedExerciseIds
5. Continue until all required slots are filled
6. Optionally fill optional slots if valid
7. Return the full generated session
