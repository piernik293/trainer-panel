==================================================
4. INTERPRETATION OF THE TABLE
==================================================

The source contains:

- recommended sets per training session
- maximum weekly sets

When a weekly value is a range, for example:

8–10

interpret it as:

- 8 = weeklyPreferredCeiling
- 10 = weeklyAbsoluteCeiling

The lower value is not a required weekly minimum.

A plan may contain fewer than 8 effective sets.

The automatic planning interface should normally stay at or below the preferred ceiling.

A plan must never be activated above the absolute ceiling.

When the weekly value is a single number:

4

store:

- weeklyPreferredCeiling = 4
- weeklyAbsoluteCeiling = 4

When the session value is a range:

2–4

store:

- sessionMin = 2
- sessionMax = 4

When the session value is a single number:

4

store:

- sessionMin = 4
- sessionMax = 4

Session values are planning guidelines.

They generate trainer-visible warnings but do not act as hard minimum requirements.

Do not show a below-session-minimum warning on a day where the target received 0 effective sets.

==================================================
10. EFFECTIVE WEEKLY VOLUME
==================================================

Use the existing exercise-muscle coefficients.

For a direct muscle target:

effective sets =
working sets × assigned coefficient

Weekly effective sets =
sum across all exercises and all workout days

Example:

Podciąganie na drążku — 3 working sets

Approved volume targets:

- Mięsień najszerszy grzbietu, coefficient 1.0 → 3.0
- Mięsień czworoboczny grzbietu, coefficient 0.25 → 0.75
- Mięsień dwugłowy ramienia, coefficient 0.5 → 1.5

Do not calculate Mięsień obły większy in this feature.

Only working sets count.

Warm-up sets do not count.

Do not round before validation.

Display final values with a maximum of one decimal place.

==================================================
11. GROUP TARGET CALCULATION
==================================================

For an approved target containing several specific muscles, prevent one physical set from being counted several times.

For each exercise and one volume target:

target contribution =
working sets × highest coefficient among assigned muscles mapped to that target

Example:

Wyciskanie hantli nad głowę — 3 working sets

Mapped assignments:

- anterior deltoid coefficient 1.0
- lateral deltoid coefficient 0.5

Mięśnie naramienne contribution:

3 × max(1.0, 0.5) = 3.0

Do not calculate:

3 × (1.0 + 0.5) = 4.5

Use the max-coefficient rule separately for each exercise occurrence.

==================================================

- target name
- calculated weekly value
- absolute ceiling
