# TASK — Add Exercise Completeness Validation and Bulk Import System

This task extends the existing Exercise Library.

Do NOT modify any existing functionality.

Do NOT change:

- Volume Calculator
- Exercise Coefficient System
- Training Interview
- Plan Editor
- Database relationships
- Exercise Intelligence logic

Only extend the Exercise Library.

============================================================
PART 1 — EXERCISE COMPLETENESS VALIDATION
============================================================

Every exercise should have an automatic completeness status.

Possible statuses:

🟢 Complete

🟡 Incomplete

Display the status in the Exercise Library list.

============================================================
VALIDATION RULES
============================================================

An exercise is considered COMPLETE only if all required fields are filled.

Required fields:

• Exercise Name

• Primary Muscle Group

• At least one Muscle Assignment

• At least one Primary Muscle

• Movement Pattern

• Difficulty Level

• Equipment

• Training Location

• Exercise Type

• Exercise Description

• Execution Instructions

• Common Mistakes

• Coaching Tips

• Exercise Intelligence

If any required field is missing:

Status becomes:

🟡 Incomplete

============================================================
INCOMPLETE EXERCISE PANEL
============================================================

When opening an incomplete exercise, display a warning panel.

Example:

------------------------------------------------

Exercise is incomplete.

Missing information:

✓ Movement Pattern

✓ Muscle Assignments

✓ Coaching Tips

✓ Exercise Intelligence

------------------------------------------------

Each missing item should automatically disappear once completed.

============================================================
AUTOMATIC PLAN GENERATION
============================================================

Incomplete exercises must NOT be used for:

• AI workout generation

• Automatic plan generation

• Automatic substitutions

Manual selection by the trainer should still be allowed.
