TASK — Clear test client database safely

IMPORTANT

This is a destructive database cleanup task.

Do not rebuild the application.
Do not change the architecture.
Do not redesign UI.
Do not remove database tables.
Do not delete migrations.
Do not delete application code.
Do not remove schema definitions.
Do not remove API endpoints.
Do not remove trainer panel functionality.

The goal is to clear all existing test client data from the database while keeping the application structure ready for new real clients.

------------------------------------------------

1. Create backup before deleting

Before deleting anything, create a Git commit named:

backup: before clearing client database

Also create a database export/backup file if possible.

Save it as:

backups/client-data-before-clear.json

or another safe format that matches the current project.

The backup should include existing:

- clients
- surveys
- survey history if implemented
- trainer notes if implemented
- any client-related records

Do not expose secrets or environment variables in the backup.

------------------------------------------------

2. Clear client-related data only

Delete all records related to clients, including:

- clients
- surveys
- survey history
- trainer notes
- client status data
- client-related progress data if it already exists
- any other records directly linked to clients

Do NOT delete:

- database tables
- schema files
- migrations
- application users/admin account if authentication exists
- exercise library if it exists
- global settings
- app configuration
- environment variables

Use a safe transaction if possible.

Respect foreign key order.

If cascading deletes already exist, use them safely.

------------------------------------------------

3. Keep the app usable

After cleanup:

- trainer dashboard should show 0 clients
- clients list should be empty but not broken
- public survey form should still work
- submitting a new survey should create a new client normally
- trainer panel should display the new client after submission

------------------------------------------------

4. Testing

After clearing the data, verify:

- app builds successfully
- app starts correctly
- trainer panel opens correctly
- dashboard works with 0 clients
- clients list works with 0 clients
- public survey form still works
- submitting a new test survey works
- new client appears in trainer panel
- PDF export works for the new test client
- no old test clients remain

------------------------------------------------

5. Commit and push

After successful cleanup and testing, commit changes if any files were added, for example backup or cleanup script.

Use commit message:

chore: clear test client database

Then push to GitHub using Replit GitHub integration.
