==================================================
1. ONE INITIAL RULE FOR EVERY EXPERIENCE LEVEL
==================================================

For every experience level without exception:

- Brak aktywności fizycznej
- Początkujący
- Średniozaawansowany
- Zaawansowany

initialWeeklyProposal = weeklyAbsoluteCeiling

The value shown in the numeric card control must initially equal the target's
maximum recommended weekly volume.

Examples:

- weeklyAbsoluteCeiling = 8
  → initial control value = 8

- weeklyAbsoluteCeiling = 16
  → initial control value = 16

- weeklyAbsoluteCeiling = 20
  → initial control value = 20

Use exactly the same rule for all four experience levels.

Do not create a conservative exception for Brak aktywności fizycznej.

This must be the real value returned by the backend proposal calculation.
Do not implement it as a frontend-only visual replacement.
