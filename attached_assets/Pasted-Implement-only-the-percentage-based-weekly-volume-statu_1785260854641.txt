==================================================

Use the raw, unrounded effective-volume value for all status decisions.

“Rekomendowana objętość spełniona”

When:

volumeRatio > 1.00

“Ryzyko przetrenowania”

==================================================
5. DISPLAY ROUNDING
==================================================

Use raw values for status calculations.

Round only numbers displayed in the UI.

Use this custom display rounding:

- decimal part from 0.0 through 0.5 → round down,
- decimal part greater than 0.5 → round up.

Example implementation:

function roundVolumeForDisplay(value: number): number {
  const lower = Math.floor(value);
  const decimalPart = value - lower;

  return decimalPart <= 0.5
    ? lower
    : Math.ceil(value);
}

Examples:

- 9.1 → 9
- 9.5 → 9
- 9.6 → 10
- 15.1 → 15
- 15.5 → 15
- 15.6 → 16
- 24.9 → 25

Important:

The displayed rounded number must never be used to determine the status.

Example:

weeklyAbsoluteCeiling = 20

rawSelectedVolume = 24.9

Displayed value = 25

volumeRatio = 24.9 / 20 = 1.245

Status remains:

“Powyżej maks. rekomendowanej objętości”

It must not become “Ryzyko przetrenowania” only because the displayed number
was rounded to 25.
