==================================================
EXTENSIBLE EXERCISE LIBRARY
==================================================

Do not hardcode a closed list of exercises for any muscle group, body part, experience level or movement pattern.

The exercise-selection system must be database-driven and automatically support exercises added to the Exercise Library in the future.

The trainer must be able to add an unlimited number of exercises for every:

- broad body-part category
- approved volume target
- specific muscle
- movement pattern
- equipment type
- training location
- difficulty level

A newly added exercise should become eligible for plan selection automatically when it has complete and valid metadata.

Required exercise metadata for selection:

- name
- broad body-part category
- primary specific muscle
- secondary specific muscles where applicable
- muscle coefficients
- movement pattern
- difficulty or minimum recommended experience level
- required equipment
- supported training locations
- active status

Do not require a code change whenever the trainer adds another exercise.

==================================================
EXERCISE ELIGIBILITY
==================================================

When selecting exercises for an intermediate or advanced client, query the existing Exercise Library instead of using hardcoded exercise-name arrays.

An exercise may be selected only when:

- it is active
- its required equipment is available
- its location matches the client’s training location
- its difficulty is suitable for the client’s experience level
- it has valid muscle assignments
- it does not conflict with the client’s structured avoidance preferences
- it supports a movement pattern or training purpose required by the plan

Future exercises that satisfy these rules must automatically become available.

==================================================
MUSCLE AND CATEGORY COVERAGE
==================================================

Keep broad Exercise Library categories such as:

- Klatka piersiowa
- Plecy
- Barki
- Biceps
- Triceps
- Brzuch
- Pośladki
- Mięśnie czworogłowe uda
- Grupa kulszowo-goleniowa
- Łydki
- Przywodziciele

The broad category is used for navigation and filtering.

Specific muscles and approved volume targets are used for precise plan calculations.

For example, exercises under the broad category “Plecy” may target:

- Mięsień najszerszy grzbietu
- Mięsień czworoboczny grzbietu

These approved targets retain separate weekly volume calculations.

Do not create a combined “Plecy” volume ceiling.

==================================================
ADDING FUTURE EXERCISES
==================================================

The trainer must be able to create another exercise for any category or muscle without changing application code.

Example:

The trainer adds a new back exercise with:

- broad category: Plecy
- primary target: Mięsień najszerszy grzbietu
- movement pattern: vertical pull
- difficulty: intermediate
- location: gym
- equipment: cable machine
- coefficient: 1.0

After saving, the exercise should automatically:

- appear in the Exercise Library
- be available to compatible intermediate and advanced clients
- contribute to the approved latissimus weekly volume target
- be included in weekly volume calculations
- remain unavailable when the client lacks the required equipment or location

==================================================
INCOMPLETE EXERCISES
==================================================

If a newly added exercise is missing required selection metadata:

- keep it available for editing in the Exercise Library
- do not automatically select it for generated plans
- show the trainer exactly which metadata is missing
- do not guess its muscles, difficulty, movement pattern or equipment

If no eligible exercise exists for a required target or movement pattern:

- do not invent an exercise
- do not silently select an unsuitable exercise
- report the missing library coverage to the trainer
