============================================================
6. EXERCISE CARD
============================================================

After adding an exercise, display a compact card containing:

- exercise name,
- target muscle,
- equipment,
- working sets,
- repetition range,
- RIR,
- rest time.

Initial default values:

- sets: 3
- repetitions: 8–12
- RIR: 2
- rest: 90 seconds

All working-set values must be whole integers.

Trainer may edit:

- sets: integer 1–6,
- minimum repetitions: integer,
- maximum repetitions: integer,
- RIR: integer 0–5,
- rest: integer seconds.

Validate:

- minimum repetitions cannot exceed maximum repetitions,
- no decimal set counts,
- no zero working sets.
