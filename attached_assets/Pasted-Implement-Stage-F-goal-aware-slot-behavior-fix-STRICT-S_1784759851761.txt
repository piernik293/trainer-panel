PART 1 — GOAL-AWARE SLOT BEHAVIOR
====================================================

Do NOT let one generic slot behave the same for all goals.

Implement goal-aware behavior for repeated problematic slots, especially:
- upper accessory / arm slot
- upper support slot
- lower support slot

Rules:

A. Budowa sylwetki
- accessory slots may freely choose direct isolation
- biceps / triceps / lateral delt / rear delt are valid and often desirable
- do not over-constrain physique slots

B. Zwiększenie siły
- upper accessory/arm slots should prefer:
  - triceps support for pressing strength
  - rear delt / upper-back support
  - only then biceps isolation if justified by priority/preference
- do NOT let generic curl become the default arm slot across all strength outputs

C. Redukcja tkanki tłuszczowej
- accessory slots should remain efficient and sensible
- direct work is allowed, but avoid weak/regression filler
- do not let lower support become beginner-only drill selection

D. Poprawa sprawności
- accessory/support slots should prefer:
  - unilateral support
  - trunk/control support
  - carries / scapular / control-oriented support where compatible
- do NOT let classic bodybuilding curl become the default “functional” support slot

E. Cel sportowy
- accessory/support slots should prefer:
  - athletic support
  - shoulder stability / rear delt / scapular support
  - trunk/control support
  - sport-useful assistance
- do NOT default to generic bodybuilding accessory unless strongly justified
