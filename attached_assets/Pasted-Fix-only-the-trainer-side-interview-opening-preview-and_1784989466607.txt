Fix only the trainer-side interview opening, preview and editing flow.

Current incorrect behavior:

When the trainer clicks the document icon next to a client in the client list, the application opens a form that behaves like creating a new interview.

This is wrong.

Required behavior:

1. Clicking the document icon in the client list must open the client's existing current/latest submitted interview.

2. It must NOT open a blank new interview form.

3. The default state must be a read-only preview:
   - all submitted client answers are visible,
   - no input fields are editable,
   - the trainer cannot accidentally change data.

4. Add an explicit button:
   "Edytuj wywiad"

5. Only after clicking "Edytuj wywiad":
   - the existing answers become editable,
   - all fields remain prefilled with the values submitted by the client,
   - no field is cleared or reset.

6. Add:
   - "Zapisz zmiany"
   - "Anuluj"

7. "Zapisz zmiany" must update the existing survey/interview record.
   It must not create a new survey, new client or duplicate interview.

8. "Anuluj" must discard unsaved changes and return to the read-only preview.

9. A new interview must not be created from the document icon.
   A new interview is submitted separately by the client through the public client page.

"Dlaczego chcesz trenować?"

Helper text:
"Krótko — co klient chce osiągnąć i co chce poprawić."

Display it in the trainer preview as:

[exact text submitted by the client]
