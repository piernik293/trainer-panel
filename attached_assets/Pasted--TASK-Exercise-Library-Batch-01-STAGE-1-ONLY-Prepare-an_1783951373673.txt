# TASK — Exercise Library Batch 01
# STAGE 1 ONLY: Prepare and Validate Import Dataset

Prepare the first curated Exercise Library import dataset.

This task is STAGE 1 ONLY.

Do NOT import any exercises into the live database.
Do NOT modify existing database records.
Do NOT reset, reseed or migrate the database.
Do NOT create temporary exercise records.
Do NOT modify the existing 5 exercises.
Do NOT change existing exercise IDs.
Do NOT change volume guidelines, coefficients or volume formulas.

The purpose of this task is to:

1. audit the current Exercise Library schema,
2. verify canonical values,
3. verify equipment and training-location storage,
4. create a reviewable JSON file,
5. validate the complete dataset,
6. stop before database import.

EXPERIENCE LEVELS
============================================================

Use exactly four canonical levels:

- Brak aktywności fizycznej
- Początkujący
- Średniozaawansowany
- Zaawansowany

Do not create additional levels.

Do not use No Activity as a fallback for missing or invalid data.

Do not mark every exercise as suitable for Brak aktywności fizycznej.

Exercises suitable for this level should normally have:

- learningDifficulty 1–2
- jointStress Niskie or Średnie
- neurologicalFatigue 1–2
- domsPotential 1–2
- stable execution
- simple instructions
- no mandatory spotter where possible

Advanced exercises such as:

- Ab wheel rollout
- Unoszenie kolan w zwisie
- Podciąganie bez wspomagania
- Przysiad bułgarski bez podparcia
- Wyciskanie sztangi wąskim chwytem

should not automatically be assigned to Brak aktywności fizycznej.

MUSCLE ASSIGNMENTS
============================================================

Use existing canonical muscles.

Do not create duplicate muscle records.

Do not create new volume targets.

Typical coefficients:

- primary muscle: 1.00
- major secondary muscle: 0.50
- minor secondary muscle: 0.25

Requirements:

- at least one primary muscle
- normally one primary assignment
- coefficient greater than 0
- coefficient not greater than 1.00
- no meaningless stabilizer assignments
- no separate volume target for Mięsień obły większy
- existing max-coefficient-per-target logic must remain unchanged

Do not modify coefficients of the existing 5 exercises.
