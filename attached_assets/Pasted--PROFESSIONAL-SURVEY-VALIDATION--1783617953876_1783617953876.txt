VALIDATION UX

If required fields are missing:

Prevent form submission.

Display a message:

"Nie można wysłać wywiadu treningowego. Uzupełnij wymagane pola oznaczone na czerwono."

Every missing field should:

• receive a red border

• display a short error message

Example:

"To pole jest wymagane."

Automatically scroll to the first invalid field.

As soon as the user corrects the value:

• remove the red border

• remove the error message

No page refresh.
