## 3. Add small derived helpers

Implement focused deterministic helpers.

### `getFatigueBand`

Return:
- `high`
- `medium`
- `low`

Rules:
- 4–5 → `high`
- 2–3 → `medium`
- 1 → `low`
- null, undefined, invalid, or out-of-range → `medium`

### `getPriorityRank`

Lower rank means higher programming priority.

Rules:
- `Bardzo wysoki` → 0
- `Wysoki` → 1
- `Średni` → 2
- `Niski` → 3
- missing or unknown → 2

### `isHighDemandExercise`

Return true only when:
- the exercise is compound
- and neurological fatigue is at least 4

Missing data must return false.

### `getSessionTier`

Return one of:

- `primary_compound`
- `secondary_compound`
- `accessory`
- `isolation`
- `core_finisher`

Safe initial rules:

1. Recognized core or abdominal main muscle group → `core_finisher`
2. Compound with high neurological fatigue → `primary_compound`
3. Other recognized compound exercise → `secondary_compound`
4. Recognized isolation exercise → `isolation`
5. Missing or unknown classification → `accessory`

Important:
- Do not classify calves automatically as core.
- Do not use exercise names for classification.
- Do not create lists of specific exercise names.
- Do not use movement pattern to change the tier yet.
- `movementPattern` is passed through now only as a future extension point.
- All-null input must return `accessory`.

### Optional normalized classification result

You may add one small helper such as `classifyExercise()` that combines the derived values into one read-only result, but only if it reduces duplication.

It must not calculate a final weighted “AI score” yet.

Do not introduce arbitrary scoring weights in Stage 1.
