GOAL

Determine whether the active exercise library contains a sufficiently large,
safe and balanced exercise pool for clients with no previous physical activity.

Inspect only:

- active exercise-library records,
- metadata consumed by ExerciseSelectionEngineV0,
- experience eligibility,
- movement patterns,
- exercise class,
- primary and secondary muscle targets,
- equipment requirements,
- contraindication and safety metadata.

==================================================
1. LIST THE ACTIVE ELIGIBLE POOL
==================================================

List every exercise currently eligible for:

“Brak aktywności fizycznej”

Group them by:

1. knee-dominant,
2. hip-dominant / posterior chain,
3. horizontal push,
4. vertical push,
5. horizontal pull,
6. vertical pull,
7. core / trunk stability,
8. carry / general conditioning if supported,
9. smaller-muscle accessory.

For every exercise report:

- exercise ID,
- Polish name,
- movement pattern,
- exercise class,
- primary targets,
- secondary targets,
- equipment,
- current experience eligibility.

==================================================
2. CLASSIFY SUITABILITY
==================================================

Classify each exercise:

A — primary automatic choice

Appropriate for a previously inactive client:
- stable,
- simple to explain,
- easy to scale,
- low technical complexity,
- easy load control.

B — acceptable alternative

Can be used, but requires more:
- balance,
- coordination,
- mobility,
- supervision,
- technique.

C — should not be an automatic first choice

Potentially:
- too technical,
- unstable,
- high impact,
- difficult to scale,
- unnecessarily complex for this level.

Do not delete or modify Group C.
Only identify it.

==================================================

Assess these currently generated exercises:

- Pompki na kolanach
- Pompki na podwyższeniu
- Przysiad do skrzyni z masą własnego ciała
- Wykrok w tył
- Przysiad wykroczny z podparciem
- Glute bridge
- Wspięcia na palce jednostronne stojąc
- Plank
- Bird dog

For each one state:

- whether it is appropriate for Brak aktywności,
- whether it should be a primary or alternative choice,
- whether a simpler library variation exists.

Pay special attention to:

- two pushing exercises but no pulling exercise,
- multiple knee-dominant exercises,
- low posterior-chain coverage,
- unilateral calf raise for an inactive client.
