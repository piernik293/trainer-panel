## Goal

Replace reflective CORS configuration:

`cors({ credentials: true, origin: true })`

with an explicit origin allowlist.

Use these clearly named environment variables unless equivalent exact-origin variables already exist:

- `TRAINER_APP_ORIGIN`
- `CLIENT_PORTAL_ORIGIN`
- `LOCAL_TRAINER_APP_ORIGIN`
- `LOCAL_CLIENT_PORTAL_ORIGIN`

Each variable represents exactly one origin:

`scheme://hostname[:port]`

## Validation

For configured origins:

- trim whitespace,
- remove one trailing slash,
- parse with `new URL`,
- reject values containing a path other than `/`,
- reject query strings and fragments,
- reject usernames or passwords,
- store only `url.origin`,
- remove duplicates.

Do not support:

- wildcards,
- suffix matching,
- substring matching,
- arbitrary Replit domains,
- arbitrary localhost ports,
- `origin: true`,
- `Access-Control-Allow-Origin: *`.

- `TRAINER_APP_ORIGIN` is required,
- `CLIENT_PORTAL_ORIGIN` is required,
- missing or malformed required origins must throw during application startup,
- local-development origin variables must not be automatically added unless explicitly intended by existing deployment configuration.
