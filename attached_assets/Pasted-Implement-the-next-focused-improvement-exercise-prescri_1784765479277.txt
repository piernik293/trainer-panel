PART 2 — SESSION ORDERING RULES
====================================================

Implement a clear ordering hierarchy inside each session.

Default ordering principle:
1. plyometric_power / explosive primer (only when justified by goal/context)
2. main_compound
3. secondary_compound
4. isolation / accessory
5. core / trunk work
6. optional low-priority finishers

Rules:
- power / explosive drills should appear near the start of the session, not buried late as normal accessories
- main compounds should come before secondary compounds
- isolation should usually come after the main structural lifts
- core should usually be near the end unless a specific goal/context requires otherwise
- do NOT randomize ordering
- keep the order coach-like and explainable

====================================================
PART 3 — CLASS-BASED PRESCRIPTION LOGIC
====================================================

Implement different prescription behavior by exercise class.

A. plyometric_power
- must NOT default to generic hypertrophy-style 3x8–12 logic
- use lower-rep / lower-fatigue / higher-quality intent logic
- shorter exercise duration, higher movement quality emphasis
- should feel like explosive work, not bodybuilding accessory work

B. main_compound
- use the most serious prescription in the session
- more rest than isolation
- goal-sensitive rep logic:
  - strength → lower rep bias
  - hypertrophy → moderate rep bias
  - sport/power → strength-supportive but not random bodybuilding prescription

C. secondary_compound
- supportive to the session main lift
- moderate prescription
- usually less dominant than main_compound

D. isolation
- more hypertrophy/accessory-oriented prescription
- generally more reps / less rest than big compounds
- valid for physique goals and intermediate+ direct work
- should not overpower the session structure

E. core
- must NOT simply inherit generic accessory logic
- use trunk/control-oriented prescription logic
- should look different from biceps curl / triceps pushdown logic

F. regression_beginner
- keep conservative/simple prescription
- especially for no-activity and beginner contexts
- should not dominate intermediate+ full-gym plans
