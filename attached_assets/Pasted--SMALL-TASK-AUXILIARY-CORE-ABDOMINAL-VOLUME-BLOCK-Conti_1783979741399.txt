============================================================
GOAL
============================================================

Add a separate auxiliary volume block:

"Core / brzuch"

It must be independent from the existing 11 muscle-volume targets.

The block represents direct core working sets, not indirect work from
squats, deadlifts or other compound exercises.

All values must be whole integers.

============================================================
1. DEFAULT WEEKLY CORE VOLUME
============================================================

Use these deterministic recommendations:

- Brak aktywności fizycznej:
  4 working sets per week

- Początkujący:
  6 working sets per week

- Średniozaawansowany:
  6 working sets per week

- Zaawansowany:
  8 working sets per week

If core / brzuch is explicitly selected as a priority:

- add +2 weekly working sets,
- maximum automatic recommendation: 10 sets.

Do not use fractional values.

Examples:

4, 6, 8, 10

Never:

4.5, 6.5, 8.5

============================================================
2. DAY DISTRIBUTION
============================================================

Distribute direct core work across 2–3 training days.

Rules:

- use whole integers only,
- normally 2–3 sets in one session,
- place core near the end of the session,
- do not place core on every available day unnecessarily,
- preserve the exact weekly total.

Examples:

4 sets:
- 2 + 2

6 sets:
- 3 + 3
or
- 2 + 2 + 2

8 sets:
- 3 + 3 + 2

10 sets:
- 4 + 3 + 3

Prefer the selected days with the lowest current session workload.
Use day index as deterministic tie-breaking.
