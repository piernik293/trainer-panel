The purpose of this audit is to determine whether the workout generator can create a realistic, balanced and explainable weekly plan before we add any Decision Engine or Explanation Engine.

====================================================
PRODUCT CONTEXT
====================================================

This is a professional trainer SaaS.

The intended final flow is:

Client interview
→ training constraints
→ split recommendation
→ weekly volume targets
→ realistic distribution across training days
→ exercise selection
→ set assignment
→ validation
→ automatic repair
→ editable weekly plan
→ explanation of important decisions

The system must eventually be able to explain:

- why a split was selected,
- why volume was assigned to specific days,
- why an exercise was selected,
- why another exercise was rejected,
- what compromises were made,
- whether the plan is realistically executable.

However, do NOT implement explainability now.

First verify whether the underlying planning logic is correct.

CORE QUESTIONS
====================================================

1. SOURCE OF TRUTH

Determine the real source of truth for:

- weekly volume target,
- daily volume target,
- current effective volume,
- current direct volume,
- current indirect volume,
- selected exercises,
- working sets,
- exercise coefficients,
- muscle deficits,
- session capacity.

Identify whether multiple competing representations exist.

2. SPLIT FEASIBILITY

Explain exactly how a split is recommended.

Check whether the split engine evaluates:

- number of training days,
- client experience,
- training goal,
- priority muscles,
- session duration,
- recovery,
- sleep,
- stress,
- available days,
- expected session size,
- realistic muscle frequency.

Check whether the engine can detect cases such as:

- PPL across 5 days with only one Legs day,
- a priority muscle trained only once,
- very high lower-body volume concentrated in one session,
- too many muscle targets assigned to one day,
- insufficient days to satisfy weekly volume.

State clearly whether the split is:

- selected by actual scoring,
- selected through static rules,
- selected by frequency only,
- or merely mapped from a template.
