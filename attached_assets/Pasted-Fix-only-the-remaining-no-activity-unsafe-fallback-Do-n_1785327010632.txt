CURRENT PROBLEM

For “Brak aktywności fizycznej”, suitableForNoActivity exercises are currently:

- promoted to the front of the candidate list,
- hard-filtered only for some alternative-index paths.

When the safe candidate band is empty, the engine falls back to the full
candidate band.

This allowed exercises such as:

id=214
“Francuskie prostowanie ramion gumą oporową zza głowy”

to appear in automatic no-activity generation.

The previous test was relaxed to accept this behaviour.
Do not relax the product requirement.

==================================================
1. HARD SAFETY FILTER
==================================================

For automatic generation when:

ctx.isNoActivityClient === true

every automatically selected exercise must satisfy:

exercise.suitableForNoActivity === true

Apply:

exercise.suitableForNoActivity === true

Apply this to:

- altIdx = 0,
- altIdx > 0,
- normal slot selection,
- accessory fallbacks,
- lower-body supplement,
- beginner balancing replacements.

Do not rely only on learningDifficulty <= 2.

Low learning difficulty does not automatically mean that the exercise is
appropriate for a previously inactive client.

Manual or locked trainer-selected exercises are outside this automatic filter
and remain unchanged.

==================================================
2. SAFE POOL EXHAUSTION
==================================================

When no unused safe candidate exists for a required slot:

1. keep safety, equipment, contraindication and movement-pattern filters,

2. allow reuse of a suitableForNoActivity=true exercise already selected earlier
   in the current week,

3. prefer the safe exercise used least recently in the current week,

4. do not fall back to suitableForNoActivity=false or null exercises.

Safety has higher priority than exercise novelty.

Example:

If Glute bridge is the only safe legal hip-dominant exercise:

- Day 1 may use Glute bridge,
- Day 2 may repeat Glute bridge,
- do not replace it with an unsafe, technical or unrelated lower-body exercise.

==================================================
3. OPTIONAL SLOT FAILURE
==================================================

If no safe exercise exists even after allowing safe reuse:

- skip the optional slot,
- do not insert an isolation or unrelated exercise only to reach an exercise
  count,
- return a non-blocking structural warning.

Warning:

“Brak kolejnego bezpiecznego ćwiczenia dla poziomu Brak aktywności fizycznej —
zachowano prostszy układ planu.”

Do not turn a valid safe plan into a blocking failure solely because an optional
slot is empty.
