PART 1 — DIFFERENTIATE THESE GOALS CLEARLY
====================================================

Implement clear behavioral differences between:

1. Poprawa kondycji
2. Poprawa sprawności
3. Cel sportowy

Rules:

A. Poprawa kondycji
- prioritize conditioning-compatible exercise choices
- prefer simple, repeatable, manageable movement patterns
- minimize unnecessary isolation clutter
- do NOT treat this as a power/plyo goal by default
- cardio / conditioning bias may exist, but this task should focus only on exercise selection profile, not full cardio programming

B. Poprawa sprawności
- prioritize movement quality, unilateral control, trunk control, coordination, athletic generalism
- allow some dynamic / “alive” movement patterns when level allows
- but do NOT treat this like full sport-performance programming
- this goal should feel more athletic than plain conditioning, but less specialized than sport

C. Cel sportowy
- this must use the extra sport-priority inputs from the UI
- it should produce more clearly athletic / performance-oriented exercise choices than "Poprawa sprawności"
- it should be the strongest context for power / dynamic / stabilization logic

PART 2 — USE THE SPORT PRIORITY SUBFIELDS
====================================================

The UI contains sport-related selections such as:
- dynamika
- szybkość
- stabilizacja
(and hobby / zawodowo status)

These must now influence exercise selection meaningfully.

Implement these profiles:

A. dynamika
- stronger power / explosive bias
- athletic / reactive movements can be favored when level allows
- support with force-production movements
- allow repeated athletic exposures through the week

B. szybkość
- prefer exercises supportive of speed qualities:
  - force production
  - unilateral drive
  - athletic pull/push/lower patterns
  - less random bodybuilding clutter
- do NOT simply map this to “more jumps”; keep it speed-supportive, not cartoonish

C. stabilizacja
- prioritize control-oriented choices:
  - unilateral stability
  - trunk control
  - anti-rotation / bracing / controlled landing / body control
- this should not mean “everything becomes rehab”
- it should still fit the user's level and training setting

D. hobby vs zawodowo
- zawodowo should allow a stronger athletic bias / repeated exposures than hobby
- hobby should remain more conservative unless other inputs strongly justify athletic emphasis

====================================================

1. Power / plyometric selections should only appear when justified by:
- goal context
- sport priority context
- experience level
- no obvious incompatibility

3. For:
- sport goal + dynamika
- explicit power-oriented context
- intermediate+

not just one random jump exercise.

5. For beginners / no activity / plain conditioning / plain hypertrophy:
- power drills should remain restricted unless strongly justified
