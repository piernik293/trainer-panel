### 3. What is the safest integration point?

Compare these possible approaches:

A. Sort only `toAdd[]` before adding exercises.

B. Add exercises first, then sort the entire day once after Auto Fill completes.

C. Insert each new exercise directly into its correct session position.

D. Change selection order inside `selectExercisesForDay()`.

For each option, assess:
- implementation complexity
- regression risk
- effect on existing manual exercise order
- effect on core insertion behavior
- ability to place a new compound before an existing isolation
- future compatibility with manual drag-and-drop ordering
- future compatibility with priority muscles

Recommend one approach.

The recommendation must preserve this behavior:

- Auto Fill may organize the whole session after it finishes.
- Normal manual editing must not repeatedly override trainer-created order.
- The exercise selection result must remain unchanged.
- Existing exercises must not disappear or duplicate.
- Core exercises must remain last unless future explicit logic says otherwise.
