==================================================
PRIORITY MODEL
==================================================

Use the existing tier model:

- Tier A = main priority muscle or main priority exercise focus
- Tier B = supporting muscles
- Tier C = general development / maintenance

This task is about making Tier A and Tier B affect session generation and exercise selection.

==================================================
REQUIRED BEHAVIOR
==================================================

If a muscle is Tier A, the generator should prefer:

1. BETTER SLOT POSITION
- priority muscle should appear earlier in the session when possible
- priority muscle should receive main or secondary compound slots before low-priority muscles

2. MAIN LIFT SUPPORT
- if the priority muscle has a suitable main lift available, it should prefer it
- example:
  - chest priority -> bench / DB press / incline press should be prioritized over machine-only filler work
  - back priority -> row / pull-up / pulldown should be prioritized over low-value accessories

3. FREQUENCY PREFERENCE
- if the split allows it, priority muscles should receive more than one meaningful exposure across the week
- do NOT force impossible frequency
- use preference, not hard failure

4. PROTECTION FROM CUTS
- when session length is limited (max 6 exercises),
  Tier A should be the last thing removed
- Tier B should be reduced after Tier C
- Tier C is the first candidate to lose optional volume

5. EXERCISE VARIETY
- do not repeat the same type of stimulus for the priority muscle across all exposures
- avoid building all priority volume from near-identical exercises

6. SUB-TARGET DIVERSITY
- where bias metadata exists, use it as a preference layer

Example:
If chest is priority:
- prefer a combination such as flat + incline
- do not build all chest work only from one angle unless equipment constraints force it

This is NOT a separate weekly volume system for upper chest/lower chest.
This is only exercise-selection quality.

==================================================
CHEST EXAMPLE (VERY IMPORTANT)
==================================================

If chest is Tier A:
- at least one main chest press should appear early in the week
- if a second meaningful chest exposure exists, prefer variety:
  - flat bench + incline bench
  - or flat DB press + incline DB press
  - or bench + dips
depending on equipment and split

Do not generate:
- all chest work from one angle only
- only machine chest work when better barbell/dumbbell options exist and the goal supports them

If goal suggests strength focus (e.g. bench-related goal),
prefer a more specific chest main lift.

==================================================
BACK / SHOULDERS EXAMPLES
==================================================

If back is Tier A:
- prefer at least one strong pull compound early
- across the week prefer both vertical and horizontal pull when feasible

If shoulders are Tier A:
- prefer press + lateral / rear delt diversity when feasible
- do not build all shoulder work from only one pattern
