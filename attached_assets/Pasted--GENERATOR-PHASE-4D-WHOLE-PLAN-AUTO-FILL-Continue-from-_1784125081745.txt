============================================================
2. AUTO-FILL FLOW
============================================================

After the trainer clicks the button:

For every workout day:

1. Read the current Phase 4B3 uncovered targetIds and Core need.
2. Skip the day when nothing remains uncovered.
3. Send exactly one existing recommendation request for that day.
4. Include:
   - uncovered targetIds,
   - includeCore,
   - exercise IDs already present in the day.
5. Process returned recommendations in their existing order.
6. For every uncovered target choose the first compatible recommendation that:
   - supports that exact targetId,
   - is not already present or selected for that day,
   - is not avoided by the client.
7. Add one exercise only once even when it supports several uncovered targets.
8. Add at most one direct Core exercise and place it at the bottom.

Do not request recommendations separately for every target.

Do not create request loops.

Maximum: one recommendation request per workout day.

============================================================

- avoided exercises,
- inactive exercises,
- incomplete exercises,
- incompatible location or equipment,
- exercises without an exact valid target assignment.
