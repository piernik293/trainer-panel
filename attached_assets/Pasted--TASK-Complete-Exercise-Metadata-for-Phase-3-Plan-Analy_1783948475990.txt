# TASK — Complete Exercise Metadata for Phase 3 Plan Analysis

This task improves the quality of the existing Exercise Library data so that Workout Builder Phase 3 can correctly analyse:

- movement categories,
- specific movement patterns,
- compound vs isolation exercises,
- bilateral vs unilateral exercises,
- planes of motion,
- suitability for experience levels,
- exercise difficulty and fatigue characteristics.

This is a DATA QUALITY AND METADATA COMPLETION task.

Do NOT add a new Workout Builder phase.
Do NOT implement automatic workout generation.
Do NOT implement AI.
Do NOT redesign the Exercise Library.
Do NOT import hundreds of new exercises during this task.

============================================================
IMPORTANT SAFETY RULES
============================================================

Preserve all existing functionality.

Do NOT:

- modify the Volume Calculator formula,
- modify approved volume-guideline values,
- modify the existing 44 guideline rows,
- modify the four experience levels,
- change muscle coefficients without explicit evidence of an error,
- delete existing muscle assignments,
- create additional volume targets,
- create a twelfth volume target,
- delete existing exercises,
- replace existing Exercise Library IDs,
- reset or reseed the database,
- modify Workout Builder Phase 1,
- modify Workout Builder Phase 2,
- modify Workout Builder Phase 3 formulas or thresholds,
- modify Training Interview logic,
- implement automatic exercise replacement.

Specific anatomical muscles may remain assigned to exercises even when they are not separate volume targets.

Example:

- Mięsień obły większy may remain a specific secondary muscle assignment.
- It must not become a new independent volume target.
- It should map into an existing relevant target where the current target-membership architecture supports it.
- The existing maximum-coefficient logic within one volume target must remain unchanged.

============================================================
OBJECTIVE
============================================================

Audit and complete the metadata of all exercises currently stored in the Exercise Library.

The current database contains only a small number of exercises, including approximately:

- Plank
- Podciąganie na drążku

- Wyciskanie sztangi leżąc

- Phase 3 movement analysis,
- Exercise Recommendation Engine,
- No Activity exercise ranking,

- future bulk import templates.

NO-ACTIVITY METADATA QUALITY
============================================================

For exercises suitable for:

"Brak aktywności fizycznej"

verify that their metadata supports the existing introductory-stage scoring.

Preferred characteristics:

- learningDifficulty: 1–2
- jointStress: Low or Medium
- neurologicalFatigue: 1–2
- domsPotential: 1–2
- stable execution
- simple movement pattern
- no mandatory spotter where possible
- complete execution instructions
- clear coaching tips
- available regression
- active status

Do not mark a technically advanced exercise as suitable for No Activity only to avoid a completeness warning.

Suitability must be honest.
