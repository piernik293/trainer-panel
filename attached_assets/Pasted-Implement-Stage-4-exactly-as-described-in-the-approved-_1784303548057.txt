3. Movement balance
--------------------------------------------------

IMPORTANT:

Unlike the architecture draft, DO NOT measure movement balance using accumulated SETS.

Instead measure:

number of exercises already committed for the same movement category.

Example:

Bench
↓

push = 1

OHP
↓

push = 2

Not:

Bench 4 sets
↓

push = 4

Reason:

Volume is already represented by ScoreTuple indices 0–3.

Movement balancing should only encourage movement variety.

Return:

0 = pattern not yet used

1 = one exercise already exists

2 = two exercises

etc.

(neutral)
