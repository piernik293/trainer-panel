============================================================
PURPOSE OF THE NO-ACTIVITY STAGE
============================================================

The main purpose of this stage is not maximal hypertrophy, maximal strength or maximum fatigue.

The primary priorities are:

1. Learning very good exercise technique
2. Learning basic movement patterns
3. Improving body awareness
4. Improving movement control
5. Improving coordination
6. Improving balance
7. Improving core stability
8. Preparing joints, muscles and connective tissues for regular training
9. Developing tolerance to physical effort
10. Building regular training habits
11. Preparing the client to safely enter the Beginner level

Movement quality must be prioritized over training intensity.

The stage should teach repeatable, controlled movement.

============================================================
TECHNIQUE-FOCUSED TRAINING PROFILE
============================================================

For clients with "Brak aktywności fizycznej", current recommendation systems should prefer exercises that are:

- Simple
- Stable
- Easy to learn
- Easy to regress
- Easy for the trainer to observe and correct
- Low in technical complexity
- Low or moderate in joint stress
- Low in neurological fatigue
- Low or moderate in DOMS potential
- Suitable for controlled tempo
- Suitable for leaving several repetitions in reserve
- Suitable without a spotter where possible

The application should emphasize:

- controlled repetitions
- stable starting position
- clear range of motion
- simple coaching cues
- consistent technique
- gradual progression
- stopping the set when technique deteriorates

Do not automatically prescribe high fatigue.

============================================================
BASIC MOVEMENT PATTERNS
============================================================

The stage should mainly develop basic patterns such as:

- Squat
- Hip hinge
- Horizontal push
- Horizontal pull
- Basic vertical pull regression
- Basic split stance or lunge pattern
- Carry
- Anti-extension core
- Anti-rotation core
- Basic locomotion
- Basic coordination

Prefer simple variations before advanced versions.

Examples:

- Box squat before a technically demanding barbell squat
- Goblet squat before a heavy back squat
- Hip hinge drill before a loaded Romanian deadlift
- Supported machine row before a difficult unsupported free-weight row
- Incline push-up before a floor push-up
- Lat pulldown or assisted pull-up before an unassisted pull-up
- Dead bug before advanced hanging abdominal exercises
- Supported split squat before a difficult walking lunge
- Farmer carry with a controlled load before advanced carry variations

Do not automatically replace the trainer’s selection.

Rank and warn while keeping manual trainer control.

============================================================
MOTOR PREPARATION
============================================================

The No Activity stage should have a strong but simple motor-preparation focus.

Current or future-ready exercise metadata should support prioritizing:

- Basic mobility preparation
- Joint-control exercises
- Coordination
- Balance
- Core stability
- Scapular control
- Pelvic control
- Breathing control
- Basic unilateral preparation
- Basic range-of-motion work
- Movement-pattern drills
- Low-intensity locomotion

Do not create an advanced athletic-performance program.

Motor preparation should be appropriate for a previously inactive person.

Do not introduce complex agility, plyometric or Olympic-lifting systems in this task.

============================================================
INTENSITY AND FATIGUE
============================================================

For "Brak aktywności fizycznej", do not recommend by default:

- Training to failure
- RIR 0 as a default
- Very high RPE
- Forced repetitions
- Drop sets
- Rest-pause
- Cluster sets
- Myo-reps
- Complex supersets
- Advanced tempo-overload methods
- High-fatigue circuits
- Advanced Olympic-lifting variations
- Highly unstable exercise variations

Preferred approach:

- several repetitions in reserve
- moderate effort
- controlled tempo
- technical consistency
- conservative progression
- manageable soreness
- adequate recovery

Do not hardcode one identical RIR or RPE for every exercise.
