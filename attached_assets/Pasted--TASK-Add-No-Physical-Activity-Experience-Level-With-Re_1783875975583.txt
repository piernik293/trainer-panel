# TASK — Add "No Physical Activity" Experience Level With Reduced Training Volume

This task extends the already approved training volume system.

Do NOT modify any existing logic unless explicitly requested below.

The current application already supports:

- Beginner
- Intermediate
- Advanced

Add a fourth experience level:

"No Physical Activity"

This level is intended for clients who have not trained previously or have been inactive for a long period.

------------------------------------------------------------

PURPOSE

People with no training history should NOT start with beginner volume.

Instead, they should start with approximately 50% of beginner training volume to:

- Reduce excessive DOMS
- Improve recovery
- Improve exercise adherence
- Allow gradual adaptation

This level should behave as a completely separate experience level.

REQUIRED BEHAVIOUR

When the trainer selects:

"No Physical Activity"

the workout generation algorithm must use ONLY the volume limits above.

When any other experience level is selected:

- Beginner
- Intermediate
- Advanced

the application must continue using the already implemented volume tables without any modification.

------------------------------------------------------------

TRAINING INTERVIEW

The Training Interview already contains an experience level selector.

Add a new option:

"No Physical Activity"

Description:

"The client has not exercised regularly in recent months or has never performed structured resistance training."

This option should appear BEFORE Beginner.

Final order:

1. No Physical Activity
2. Beginner
3. Intermediate
4. Advanced

------------------------------------------------------------

FUTURE WORKOUT GENERATION

Clients classified as "No Physical Activity" should automatically receive:

- Beginner-friendly movement patterns
- Conservative weekly training volume
- No advanced intensity techniques
- Emphasis on movement quality
- Gradual progression toward Beginner volume over time
