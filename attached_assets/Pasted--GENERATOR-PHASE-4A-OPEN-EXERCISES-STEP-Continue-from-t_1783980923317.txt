============================================================
3. MANUAL EXERCISE SELECTION
============================================================

After clicking "Dodaj ćwiczenie", open a compact selector using the existing
Exercise Library.

Allow the trainer to:

- search by exercise name,
- filter by target muscle,
- filter by available equipment,
- select an existing exercise,
- add it to the selected workout day.

Rules:

- use stable existing exercise IDs,
- do not create new exercises,
- exclude inactive exercises,
- exclude exercises incompatible with available equipment or location,
- do not duplicate Exercise Library data inside generator code.

============================================================
4. CLIENT WARNINGS
============================================================

"Klient wskazał, że chce unikać tego ćwiczenia."

Require manual confirmation:

"Zastosuj mimo ostrzeżenia"

Do not permanently block trainer selection.

If existing pain or contraindication data creates a conflict, show a
non-blocking warning.

Do not diagnose and do not prescribe rehabilitation.

============================================================
5. EXERCISE CARD
============================================================

After adding an exercise show:

- exercise name,
- target muscle,
- equipment,
- working sets,
- repetition range,
- RIR,
- rest time.

Defaults:

- sets: 3
- repetitions: 8–12
- RIR: 2
- rest: 90 seconds

Trainer may edit:

- sets: whole integer 1–6,
- minimum repetitions: whole integer,
- maximum repetitions: whole integer,
- RIR: whole integer 0–5,
- rest: whole integer seconds.

Validation:

- reject decimal set counts,
- reject zero sets,
- minimum repetitions cannot exceed maximum repetitions.

============================================================
6. EXERCISE ORDER

Do not allow dragging exercises between different workout days.

New normal exercises should be added before the Core section.

Core exercises should remain at the bottom of the workout day.

Do not implement automatic exercise ordering yet.
