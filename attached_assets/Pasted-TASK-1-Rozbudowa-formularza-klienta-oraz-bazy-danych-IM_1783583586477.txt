TASK 1 – Rozbudowa formularza klienta oraz bazy danych

IMPORTANT

Nie przebudowuj obecnej aplikacji.

Nie zmieniaj obecnej architektury projektu.

Nie usuwaj żadnych istniejących funkcji.

Nie zmieniaj obecnego wyglądu aplikacji.

Nie usuwaj istniejących danych z bazy PostgreSQL.

Jeżeli konieczne są zmiany w bazie danych, wykonaj migracje zachowujące pełną kompatybilność.

Kod powinien pozostać zgodny z React + Vite + Tailwind + shadcn/ui + Node.js + Express + PostgreSQL + Drizzle ORM.

Po zakończeniu upewnij się, że aplikacja nadal działa poprawnie.
